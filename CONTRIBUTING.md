# Contributing

Thanks for your interest in improving this profile repository.

## Scope

This repository is primarily used for the GitHub profile README for `Makhmeto`.

Good contribution targets include:

- Fixing broken links or badges
- Improving wording
- Updating public project references
- Improving repository automation or templates

## Workflow

1. Open an issue for non-trivial changes.
2. Create a pull request with a clear summary.
3. Verify that `README.md` renders correctly.
4. Confirm that no secrets, private information, or unverifiable claims are included.

## Quality Bar

- Keep claims factual and verifiable.
- Prefer concise wording.
- Do not add private client details or credentials.
- Keep generated images and badges from reputable sources.
