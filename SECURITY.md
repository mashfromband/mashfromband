# Security Policy

## Reporting

If you find a security issue in this repository, please do not open a public issue with sensitive details.

Report it privately to the repository owner through GitHub.

## What To Avoid

Do not add:

- API keys, tokens, passwords, or private keys
- Private customer or project information
- Non-public financial or operational details
- Credentials in screenshots, logs, or linked assets

## Supported Scope

This repository contains profile content and GitHub workflow configuration. Security review focuses on preventing secret exposure and keeping automation permissions minimal.
